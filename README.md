# 📊 Predictive Analytics Using Historical Sales Data

A machine learning project that uses historical sales data to predict future sales. The project generates reproducible synthetic daily sales data, performs chronological aggregation, creates time-based and lag features, trains a **Random Forest Regression** model, evaluates its performance on an untouched test period, and generates data for visualization in **Power BI**.

## 🚀 Project Overview

This project demonstrates an end-to-end predictive analytics workflow:

* Generate synthetic historical sales data
* Prepare and aggregate daily sales data
* Create calendar and lag-based features
* Split the data chronologically into training and testing periods
* Train a Random Forest regression model
* Evaluate model performance using the held-out test period
* Generate future sales forecasts
* Export reports and CSV files
* Visualize historical sales and predictions using Power BI

The project uses synthetic data, making it suitable for demonstration and learning purposes.

## ▶️ Running the Project

Run the main Python script:

```bash
python main.py
```

The script starts the project pipeline from the project's `src` directory.

The pipeline generates historical sales data, prepares the data chronologically, reserves the final 20% as a test period, trains a Random Forest regression model, and calculates evaluation metrics.

## 🤖 Machine Learning Approach

### Model

The project uses:

**Random Forest Regression**

The model uses features such as:

* Calendar features
* Historical sales values
* Lag features
* Other features generated during the preprocessing pipeline

### Train/Test Split

The data is split chronologically rather than randomly.

* **Training data:** First 80%
* **Testing data:** Final 20%

This approach helps prevent future information from leaking into the training data.

## 📈 Model Evaluation

The model is evaluated using the reserved test period.

The generated model report contains the measured evaluation metrics and the total forecast for the future period.

Report location:

```text
outputs/reports/model_report.txt
```

## 🔮 Future Forecasting

After training the model, the pipeline generates future sales predictions.

A **30-day future forecast** is produced for visualization and analysis.
